# AI Multi-API Telegram Bot

یک ربات تلگرامی پیشرفته با پایتون برای اتصال به هوش‌مصنوعی‌های مختلف (OpenAI, Gemini, Custom APIs).

## ویژگی‌ها
- 🎛 پنل مدیریت شیشه‌ای (Inline UI)
- 🔄 افزودن داینامیک API و مدل‌ها
- 🧠 حفظ تاریخچه مکالمات و قابلیت ریست حافظه
- 🌐 پشتیبانی از معماری‌های OpenAI و Gemini

## راه‌اندازی سریع
تنها کافیست متغیرهای محیطی زیر را تنظیم کنید:
- `BOT_TOKEN`: توکن ربات تلگرام شما
- `ADMIN_ID`: شناسه عددی اکانت تلگرام شما
