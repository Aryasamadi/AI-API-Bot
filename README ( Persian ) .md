راهنمای جامع و کامل ربات API هوش مصنوعی (صفر تا صد)

۱. معرفی ربات
این ربات یک واسط تلگرامی برای اتصال به چندین مدل هوش مصنوعی مختلف (مثل ChatGPT، DeepSeek، Claude، Gemini و...) است. شما میتوانید چندین روتر (API) با کلیدهای مختلف اضافه کنید و کاربران با انتخاب هر مدل، مستقیماً با آن چت کنند. ربات از دیتابیس محلی (SQLite) و همچنین دیتابیس ابری (مانند Cloudflare D1 یا هر سرویس دیگر) پشتیبانی میکند.

۲. امکانات اصلی
- مدیریت چندین روتر API (هر روتر شامل آدرس Base URL و توکن مجزا)
- افزودن و حذف مدل‌ها برای هر روتر به‌صورت مجزا
- انتخاب مدل توسط کاربر و شروع چت
- ذخیره تاریخچه چت (۱۰ پیام آخر) برای هر کاربر
- پنل مدیریت کامل شامل: تنظیم رمز عبور، کانال اجباری، ارسال پیام همگانی، پاک کردن کش و پاک‌سازی کامل دیتابیس
- پشتیبانی از ۹ زبان زنده دنیا (انگلیسی، فارسی، روسی، عربی، هندی، ترکی، فرانسوی، آلمانی، چینی)
- نمایش نام مدل‌ها به صورت مونو (قابل کپی با یک کلیک)
- ایموجی‌های اختصاصی برای مدل‌ها (مثلاً 🐟 برای DeepSeek و 🧠 برای GPT)

۳. پیش‌نیازهای اولیه (چیزهایی که حتماً نیاز داری)
- یک اکانت تلگرام
- یک توکن ربات از @BotFather در تلگرام (ربات را بساز و توکن را کپی کن)
- آیدی عددی خودت در تلگرام (از ربات @userinfobot بپرس)
- یک سرویس هاست مانند Railway (رایگان است) یا یک سرور VPS شخصی

۴. متغیرهای محیطی (Environment Variables) – مهم
ربات این متغیرها را از فایل .env یا از قسمت Variables در هاست (مثل Railway) می‌خواند.

متغیرهای اجباری (همه حتماً باید داشته باشند):
BOT_TOKEN = همان توکنی که از @BotFather گرفتی
ADMIN_ID = آیدی عددی خودت در تلگرام

اگر می‌خواهی از دیتابیس ابری استفاده کنی، دو راه داری:

راه اول: استفاده از Cloudflare D1 (پیش‌فرض و رایج)
DB_PROVIDER = cloudflare
CLOUDFLARE_ACCOUNT_ID = آیدی اکانت کلودفلر
CLOUDFLARE_D1_DATABASE_ID = آیدی دیتابیس D1 که ساختی
CLOUDFLARE_API_TOKEN = توکن API با دسترسی D1:Edit

راه دوم: استفاده از هر دیتابیس ابری دیگر (عمومی)
DB_PROVIDER = generic
CLOUD_API_URL = آدرس API دیتابیس خارجی (مثلاً https://api.supabase.co/...)
CLOUD_API_TOKEN = توکن مربوط به آن سرویس
CLOUD_QUERY_BODY = قالب JSON درخواست مانند {"sql": "query", "params": []}

نکته مهم: اگر متغیرهای ابری را تنظیم نکنی یا ناقص بگذاری، ربات به‌طور خودکار به دیتابیس محلی (SQLite) برمی‌گردد و بدون مشکل کار می‌کند. این برای تست یا استفاده کم‌حجم عالی است.

۵. روش‌های راه‌اندازی (گام به گام)

روش اول: راه‌اندازی روی Railway (آسان‌ترین روش)
۱. اگر اکانت گیت‌هاب نداری، بساز. سپس این مخزن (Repository) را Fork کن (دکمه Fork در بالای صفحه).
۲. به سایت Railway.app برو و با اکانت گیت‌هاب وارد شو.
۳. روی New Project کلیک کن و گزینه Deploy from GitHub repo را انتخاب کن.
۴. مخزنی که Fork کردی را انتخاب کن. Railway به‌طور خودکار شروع به دیپلوی می‌کند (۱ تا ۲ دقیقه طول می‌کشد).
۵. بعد از اتمام دیپلوی، به بخش Variables در داشبورد پروژه‌ات برو.
۶. متغیرهای BOT_TOKEN و ADMIN_ID را دقیقاً با همان نام‌ها اضافه کن.
۷. (اختیاری) اگر دیتابیس کلودفلر داری، متغیرهای مربوط به آن را نیز اضافه کن. اگر نداری، این مرحله را رد کن.
۸. پس از افزودن متغیرها، Railway به‌طور خودکار دوباره دیپلوی می‌کند. منتظر بمان تا تمام شود.
۹. ربات تو الان روشن است. تلگرام را باز کن، ربات را پیدا کن (با یوزرنیمش) و برایش /start بفرست. از تو می‌خواهد زبان را انتخاب کنی، سپس لیست مدل‌ها را نشان می‌دهد. اما صبر کن! هنوز مدلی وجود ندارد. باید خودت آن‌ها را اضافه کنی.

روش دوم: راه‌اندازی روی سرور شخصی (VPS)
۱. روی سرور خود (مثل اوبونتو) پایتون ۳.۹ یا بالاتر، git و pip را نصب کن.
۲. مخزن را روی سرور کلون کن: git clone آدرس_مخزن_خودت
۳. داخل پوشه پروژه یک فایل به اسم .env بساز و متغیرهای BOT_TOKEN و ADMIN_ID را در آن بنویس.
۴. در ترمینال، داخل همان پوشه، این دستور را بزن تا کتابخانه‌ها نصب شوند:
   pip install aiogram aiohttp aiosqlite python-dotenv
۵. سپس ربات را اجرا کن:
   python bot.py
۶. ربات تا زمانی که ترمینال باز است، روشن می‌ماند. برای اینکه در پس‌زمینه اجرا شود، از screen یا tmux استفاده کن.

روش سوم: تست روی کامپیوتر شخصی (بدون سرور)
همان روش VPS را انجام بده، فقط کافی است پایتون را روی سیستم خودت نصب کنی و دستورات را اجرا کنی. ربات با دیتابیس محلی کار می‌کند.

۶. نحوه اضافه کردن مدل‌ها (کارهای مدیریتی)
وقتی ربات برای اولین بار اجرا می‌شود، هیچ مدلی ندارد. برای اضافه کردن مدل، این مراحل را انجام بده:
۱. به ربات در تلگرام پیام /admin بفرست (فقط کسی که ADMIN_ID را وارد کرده، اجازه دارد).
۲. روی دکمه "➕ افزودن روتر" کلیک کن.
۳. از تو سه مرحله خواسته می‌شود:
   - آدرس Base URL: مثلاً https://api.openai.com/v1 (برای OpenAI)
   - کلید API (توکن): کلید مخفی خود را وارد کن
   - نام دقیق مدل: مثلاً gpt-3.5-turbo
۴. بعد از افزودن روتر، می‌توانی با رفتن به جزئیات آن روتر و کلیک روی "➕ افزودن مدل"، مدل‌های بیشتری به همان روتر اضافه کنی.
۵. حالا کاربران (و خودت) می‌توانند مدل مورد نظر را انتخاب کنند و چت را شروع کنند.

۷. رفع اشکالات رایج

مشکل: ربات استارت نمی‌خورد یا خطا می‌دهد.
راه‌حل: چک کن که BOT_TOKEN و ADMIN_ID را درست و کامل وارد کرده‌ای. آیدی ادمین باید عدد باشد، نه متن.

مشکل: خطای "Cloudflare vars missing" می‌بینم.
راه‌حل: اگر قصد استفاده از کلودفلر نداری، این خطا را نادیده بگیر. ربات به‌صورت خودکار به SQLite محلی سوئیچ می‌کند.

مشکل: متغیرهای کلودفلر را اضافه کردم اما ربات همچنان از دیتابیس محلی استفاده می‌کند.
راه‌حل: نام متغیرها را دقیقاً مطابق راهنما (حساس به بزرگ و کوچکی) چک کن. حتماً DB_PROVIDER=cloudflare را هم اضافه کن. بعد از تغییر متغیرها، حتماً ربات را ری‌استارت کن (در Railway این کار خودکار است).

مشکل: دکمه کپی کردن مدل‌ها کار نمی‌کند.
راه‌حل: نام مدل‌ها به صورت ` (بک‌تیک) نمایش داده می‌شوند. در تلگرام با نگه داشتن روی آن‌ها، گزینه کپی ظاهر می‌شود.

مشکل: ربات پیام‌های انگلیسی می‌دهد با اینکه زبان فارسی را انتخاب کرده‌ام.
راه‌حل: ممکن است زبان کاربر در دیتابیس ذخیره نشده باشد. دوباره دستور /lang را بفرست و زبان را انتخاب کن.


۸. سخن پایانی

محلی کاملاً پایدار است. حالا برو و ربات خودت را راه‌اندازی کن و از چت با مدل‌های مختلف لذت ببر.
